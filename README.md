# Groundwater Geology Generator -- 多层地质建模系统

基于 PyQt5 + PyVista 的交互式三维多层地质体素建模工具，用于生成包含倾斜、褶皱、断层变形的非均质地层结构，支持裂隙网络和透镜体建模，并导出 MODFLOW 友好的网格数据。

---

## 功能特性

- **多层地质建模**：支持任意数量的用户自定义地层，每层独立配置颜色、渗透系数
- **非均匀覆土层**：覆土厚度由 Perlin noise 驱动，形成自然的不均匀覆盖，部分区域裸露岩层
- **地层复杂度控制**：统一调节倾斜、褶皱、断层三种变形强度（0=水平平行 ~ 1=极端变形）
- **顶层岩层自动贴合**：最顶层岩层厚度由系统自动计算，逐点贴合覆土底面，确保岩层与土层之间无空隙
- **裂隙网络建模**：每个裂隙独立配置长度、宽度（cell）、渗透系数、颜色，裂隙之间可自然交错
- **透镜体建模**：每个透镜体独立配置半径、渗透系数、颜色，保证指定数量的透镜体全部在岩层内生成
- **交互式 3D 可视化**：基于 PyVista 的实时体素渲染，支持旋转、缩放、多视角观察
- **MODFLOW 数据导出**：导出 `.npz` 格式，包含 stratum_id、permeability、fracture_id、lens_id 等完整数组
- **VTK 可视化导出**：导出 `.vtu` 格式，可在 ParaView 中进一步分析和可视化
- **后处理窗口** (`postprocess_window.py`)：K 随机化 / 水头模拟 / 污染物运移 — 独立窗口，可从主程序接收数据或加载已有 `.npz`

## 后处理窗口功能

### K 随机化

对原始渗透系数场叠加分层百分比噪声（Perlin noise），保持层内连续性且不改变数量级：

| 参数 | 范围 | 默认值 | 说明 |
|------|------|--------|------|
| 噪声尺度 (m) | 1.0~200.0 | 20.0 | Perlin noise 空间尺度 |
| 扰动幅度 (%) | 0.0~100.0 | 20.0 | K 的百分比浮动范围 |
| 随机种子 | 0~999999 | 42 | 可重复随机化 |

- 每层独立做 3D Perlin 噪声扰动，K_new = K_base * (1 +/- amplitude_pct/100)
- 以每个单元自身 K_original 为基值 clip，保护裂隙/透镜体等非均质结构
- 层间过渡区做 log 域平滑插值

### 初始水头生成

**饱和流模式**（默认）：水头 = 地形 + 梯度 + 深度修正，所有边界 Neumann。

**非饱和流模式**（勾选"启用非饱和流模式"）：
- 上游/下游设为 Dirichlet 边界（水位按梯度方向推导）
- 地下水位高程直接输入（使用模型原始 z 坐标）
- 水位以下预加静水压力梯度（可选，默认关闭）
- 水位以上包气带水头恒等于水位

| 参数 | 范围 | 默认值 | 说明 |
|------|------|--------|------|
| 地下水位高程 (m) | -100.0~100.0 | 0.0 | 初始地下水位 |
| 梯度斜率 | -0.1~0.1 | 0.05 | 水力梯度大小 |
| 梯度方向 (rad) | 0.0~2pi | 0.0 | 梯度方向（含圆形角度旋钮） |
| 静水压预加梯度 | 0.0~5.0 | 0.0 | 0=关闭，仅影响初始猜测 |

### 稳态水头求解 (SOR)

向量化的 SOR 迭代求解 `div(K * grad(h)) = 0`：

| 参数 | 范围 | 默认值 | 说明 |
|------|------|--------|------|
| 最大迭代次数 | 100~20000 | 5000 | SOR 最大迭代 |
| 收敛容差 | 1e-8~1e-2 | 1e-6 | 残差阈值 |
| 松弛因子 omega | 0.5~2.0 | 1.0 | SOR 超松弛参数 |
| 连续耐心次数 | 1~10 | 2 | 早停条件 |
| 最小相对下降率 | 0.001~0.5 | 0.01 | 早停残差下降阈值 |

- 饱和流：全 Neumann 边界（开放系统）
- 非饱和流：上游/下游 Dirichlet，侧向 Neumann
- 支持取消按钮（迭代中点取消立即终止）
- 迭代次数/残差显示在按钮下方

### 污染物运移

**点源 Dirichlet 模型**：污染源格点浓度固定，不参与对流-弥散。

| 参数 | 范围 | 默认值 | 说明 |
|------|------|--------|------|
| 点源浓度 (mg/L) | 0.0~1e7 | 1000.0 | 每个污染源浓度 |

支持最多 3 个独立点源，通过滑块/SpinBox 定位 XYZ 坐标。

#### 污染物种类与物理参数

| 种类 | 溶解度 (mg/L) | 密度 (g/cm3) | 分子扩散 (m2/d) |
|------|---------------|-------------|-----------------|
| 自定义 | 手动输入 | 手动输入 | 手动输入 |
| 氨氮 (NH3-N) | 10000 | 0.91 | 1.0e-5 |
| 1,2-二氯乙烷 (DCE) | 8000 | 1.24 | 8.6e-6 |
| 二氯乙烯 (TCE) | 1100 | 1.22 | 7.2e-6 |

下拉菜单选择后自动填充，仍可手动修改。

#### 弥散度模式

**手动固定值**：
- 纵向弥散度 alpha_L (m)：默认 20.0
- 横向弥散度 alpha_T (m)：默认 5.0

**自适应 (基于 K)**：
- 纵向放大系数：默认 20.0
- 横向比例系数：默认 0.25
- alpha_L = 系数 * dx * (1 + 0.1 * log10(K/K_median))

其他参数：

| 参数 | 范围 | 默认值 | 说明 |
|------|------|--------|------|
| 分子扩散系数 (m2/d) | 1e-15~1e-2 | 1e-5 | 纯分子扩散 |
| 阻滞因子 R | 1.0~50.0 | 1.0 | 吸附阻滞 |
| 衰减系数 lambda (1/d) | 0.0~1.0 | 0.0 | 一级衰减 |
| 模拟时长 (天) | 1.0~36500 | 365.0 | 总模拟时间 |
| 时间步长 (天) | 0.01~365 | 1.0 | 每步时长 |

#### 运移算法

- **对流**：Semi-Lagrangian（无条件稳定，回溯 + 三线性插值）
- **弥散**：各向异性高斯卷积（沿流速方向 sigma 更大，垂直方向更小）
- **衰减**：解析解 `exp(-lambda * dt / R)`
- **Operator Splitting**：对流 1 大步 + 弥散子步

#### 显示选项

- 线性/对数色标切换
- 最小显示阈值过滤
- 色标上限模式：自动（实际最大值取整）/ 固定（源头浓度）
- 自定义白-黄-黑 colormap（线性），afmhot_r（对数）

## 地层复杂度分级

| 复杂度 | 倾斜 | 褶皱 | 断层 |
|--------|------|------|------|
| 0.0 | 无 | 无 | 无（完全水平平行） |
| 0.2 | 轻微 (<=6 deg) | 无 | 无 |
| 0.4 | 明显 (<=12 deg) | 1~2 层正弦 | 无 |
| 0.6 | 强 (<=18 deg) | 2~3 层叠加 | 开始出现 |
| 0.8 | 很强 (<=24 deg) | 3~4 层叠加 | 多条 |
| 1.0 | 极端 (<=30 deg) | 4~5 层叠加 | 多条强烈断层 |

变形公式：
- **倾斜**：`tan(theta) * (x * cos(alpha) + y * sin(alpha))`，theta in [0, 30 deg * complexity]
- **褶皱**：多层正弦波叠加，`sum A * sin(freq * (x * cos(beta) + y * sin(beta)) + phi)`
- **断层**：`throw * tanh(dist / width)`，平滑阶跃避免尖锐不连续

## 覆土层生成机制

覆土厚度不是均匀的，而是由 Perlin noise 驱动的不规则分布：

1. 生成 ridged Perlin noise 场（频率比地形噪声更高）
2. 加随机阈值（0.15~0.35）：低于阈值的区域覆土厚度 = 0（**裸露岩层**）
3. 高于阈值的区域：厚度线性映射到 [0, 用户设定最大厚度]
4. 最顶层岩层顶面逐点贴合覆土底面（`max(soil_bottom, prev_top + 0.1)`）

典型分布：约 15%--35% 区域完全裸露岩层，其余区域覆土厚度 0 至最大厚度不等。

---

## 裂隙生成机制

1. 从岩层内部随机选取起点（已排除边界外 cell）
2. 随机 3D 方向（均匀分布在单位球面）
3. 沿方向逐步前进，每步严格前进 `avg_d` 米（欧几里得距离）
4. 遇到空气、覆土层、地表或地块边界时停止
5. 路径 cell 及宽度范围内的 cell 标记为裂隙

裂隙长度单位是 **米（m）**，与实际物理长度一致。

---

## 透镜体生成机制

1. 从岩层内部随机选取中心点（已排除边界外 cell）
2. 随机三轴椭球半轴（基准半径 * 0.7~1.3 随机系数）
3. 检查椭球顶面不超过岩层顶面（不穿透覆土层）
4. 未通过则重试（最多 50 次），保证所有透镜体全部生成
5. 椭球超出网格边界的部分自然截断

## 导出格式

### 导出网格数据 (.npz)

点击"导出网格数据"按钮，保存为 NumPy `.npz` 压缩格式，包含以下数组：

| 数组名 | 形状 | 类型 | 说明 |
|--------|------|------|------|
| `stratum_id` | (nx, ny, nz) | int32 | 地层标记：0=空气, 1..N=岩层(N=strata数), N+1=覆土 |
| `permeability` | (nx, ny, nz) | float64 | 每个 cell 的渗透系数 K（裂隙/透镜体已覆盖） |
| `idomain` | (nx, ny, nz) | int32 | 1=活跃(cell有物质), 0=空白(空气) |
| `fracture_id` | (nx, ny, nz) | int32 | 裂隙标记：0=无, 1..M=裂隙编号 |
| `lens_id` | (nx, ny, nz) | int32 | 透镜体标记：0=无, 1..P=透镜体编号 |

| `soil_bottom` | (nx, ny) | float64 | 覆土底面高程（逐点不同，不均匀） |
| `inside_mask` | (nx, ny) | bool | 地块边界掩码（不规则边界） |
| `x, y, z` | 1D | float64 | 三个方向的坐标轴 |
| `dx, dy, dz` | scalar | float64 | 三个方向的网格间距 |
| `n_strata` | scalar | int | 用户岩层数量 |
| `soil_thickness_avg` | scalar | float | 覆土平均（最大）厚度 |

Python 读取示例：

```python
import numpy as np
data = np.load("geology_data.npz")

stratum_id = data["stratum_id"]       # 地层标记
K = data["permeability"]              # 渗透系数（裂隙/透镜体已覆盖）
idomain = data["idomain"]             # 活跃/空白掩码
fracture_id = data["fracture_id"]     # 裂隙标记
lens_id = data["lens_id"]             # 透镜体标记
top = data["top_elevation"]           # 地表高程
x, y, z = data["x"], data["y"], data["z"]
dx, dy, dz = data["dx"], data["dy"], data["dz"]
```

## 核心算法说明

### 生成顺序（从下到上）

```
1. 底层岩层 (strata[0])    -> 底面固定在 -depth
2. 中层岩层 (strata[1..])   -> 底面 = 上一层顶面
3. 顶层岩层 (strata[-1])    -> 顶面逐点贴合覆土底面
4. 覆土层                    -> 底面 = 顶层顶面，顶面 = 地形表面
5. 裂隙网络                  -> 后处理，在岩层 cell 中标记路径
6. 透镜体                    -> 后处理，在岩层 cell 中标记椭球区域
```

### 体素标记体系

```
0      = 空气（地表以上 或 深度以下间隙）
1      = 物理最底层岩层
2..N   = 中间岩层
N+1    = 覆土层（物理最顶层）
```

裂隙和透镜体有独立的 `fracture_id` 和 `lens_id` 数组，不修改 `stratum_id`。

### 坐标轴刻度

X、Y 轴刻度间隔固定为 20m，Z 轴刻度间隔固定为 10m，从 0 向两侧对称延伸。
刻度标签数量不限制，确保间隔严格均匀（radius=200 时显示 -220, -200, ..., 200, 220）。

### Perlin Noise

采用纯 NumPy 实现的 Perlin noise + FBM，无 C 扩展依赖，避免 segfault：
- 256 项 Ken Perlin 原始排列表
- 向量化运算（支持 ndarray 输入）
- 经典 `t^3 * (t * (t * 6 - 15) + 10)` fade 函数

## 注意事项

1. **分辨率影响速度**：XY 分辨率 > 150 时，3D 体素数量呈立方增长，生成和渲染会变慢
2. **顶层岩层厚度**：物理最顶层岩层的实际厚度 = 覆土底面 -- 前一层顶面，受地形起伏和覆土不均匀性影响，各处不同
3. **覆土厚度 = 0 时**：覆土层不生成，地表直接露出顶层岩层
4. **preset_name 字段**：每个地层独立记录最后一次使用的预设名称，修改渗透系数后不会丢失预设关联
5. **浮点精度**：渗透系数精度为 6 位小数，支持玄武岩 (1e-5) 和花岗岩 (1e-6) 级别的低渗透系数
6. **裂隙长度单位**：米（m），按欧几里得距离计算
7. **透镜体保证生成**：系统通过重试机制确保所有配置的透镜体全部在岩层内生成

## 文件说明

| 文件 | 说明 |
|------|------|
| `MapGeneration.py` | 主程序，包含完整 UI + 地质生成引擎 |
| `postprocess_window.py` | 后处理窗口，K 随机化 / 水头模拟 / 污染物运移 |
| `README.md` | 本文档 |

### 主程序 → 后处理窗口工作流

```
MapGeneration.py (生成地质模型)
    ├── 导出 .npz (网格数据)
    └── [可选] 直接传递到后处理窗口

postprocess_window.py (后处理分析)
    ├── 加载 .npz 或接收主程序数据
    ├── K 随机化 → 求解稳态水头 → 污染物运移模拟
    └── 导出含结果的 .npz 或 .vtu
```

主程序"导出网格数据"按钮生成的 `.npz` 可在后处理窗口加载；后处理窗口导出的 `.npz` 也可重新加载以继续分析。
