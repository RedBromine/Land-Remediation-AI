# Groundwater Geology Generator — 多层地质建模系统

基于 PyQt5 + PyVista 的交互式三维多层地质体素建模工具，用于生成包含倾斜、褶皱、断层变形的非均质地层结构，并导出 MODFLOW 友好的网格数据。

---

## 功能特性

- **多层地质建模**：支持任意数量的用户自定义地层，每层独立配置颜色、渗透系数
- **非均匀覆土层**：覆土厚度由 Perlin noise 驱动，形成自然的不均匀覆盖，部分区域裸露岩层
- **地层复杂度控制**：统一调节倾斜、褶皱、断层三种变形强度（0=水平平行 ~ 1=极端变形）
- **顶层岩层自动贴合**：最顶层岩层厚度由系统自动计算，逐点贴合覆土底面，确保岩层与土层之间无空隙
- **交互式 3D 可视化**：基于 PyVista 的实时体素渲染，支持旋转、缩放、多视角观察
- **MODFLOW 数据导出**：导出 `.npz` 格式，包含 stratum_id、permeability、idomain、top_elevation 等完整数组
- **VTK 可视化导出**：导出 `.vtu` 格式，可在 ParaView 中进一步分析和可视化

## 界面说明

### 基础参数

| 参数 | 范围 | 默认值 | 说明 |

| 区域半径 (m) | 10~1000 | 100 | 地块平面半径 |
| 边界不规则度 | 0.0~1.0 | 0.3 | 0=完美圆形，1=极不规则 |
| 地下深度 (m) | 1~500 | 50 | 最底层岩层底面深度 |
| 最大地表高度 (m) | 1~500 | 15 | 地面最高点高程 |
| XY 网格分辨率 | 20~300 | 80 | 网格密度，越大越精细但越慢 |
| 覆土厚度 (m) | 0.0~50.0 | 5.0 | 覆土最大厚度（实际分布不均匀） |
| 地层复杂度 | 0.0~1.0 | 0.3 | 控制倾斜+褶皱+断层的综合强度 |

### 噪声参数

| 参数 | 范围 | 默认值 | 说明 |
|------|------|--------|------|
| 地形起伏尺度 | 5~300 | 60 | 越大地形越平缓 |
| 噪声叠加层数 | 1~10 | 5 | FBM 八度数量 |
| Persistence | 0.1~1.0 | 0.5 | 每层振幅衰减比例 |
| Lacunarity | 1.0~5.0 | 2.0 | 每层频率增长比例 |

### 地层管理

列表显示顺序为**从上到下**（物理从上到下）：
- **第 0 行 [覆土]**：固定不可删除，双击可编辑名称、颜色、渗透系数
- **第 1 行 [1]**：物理最顶层岩层，厚度由系统自动计算
- **第 2~N 行 [2..N]**：用户自定义岩层，可编辑平均厚度、颜色、渗透系数
- **第 N+1 行 [N+1]**：物理最底层岩层

操作按钮：
- `+ 添加`：在顶部（覆土正下方）添加新岩层
- `- 删除`：删除选中岩层（覆土层不可删）
- `编辑`：打开编辑对话框修改岩层属性
- `上移/下移`：调整岩层在列表中的位置（即调整物理上下顺序）
- `恢复默认`：重置为 3 层默认岩层 + 默认覆土层

### 编辑地层对话框

- **地层名称**：自定义显示名称
- **预设类型**：8 种预设岩层（黏土、砂岩、泥岩、石灰岩、页岩、砾岩、玄武岩、花岗岩、自定义），选择后自动填充颜色和渗透系数
- **平均厚度 (m)**：岩层的平均厚度（仅非顶层岩层可设置，实际厚度会被复杂度扰动）
- **渗透系数 K**：该岩层的渗透系数，精度到 6 位小数
- **地层颜色**：点击颜色块打开颜色选择器

> 顶层岩层的编辑对话框不显示"平均厚度"选项，因为其厚度由系统自动计算（覆土底面 − 前一层顶面，逐点贴合）。

## 地层复杂度分级

| 复杂度 | 倾斜 | 褶皱 | 断层 |
|--------|------|------|------|
| 0.0 | 无 | 无 | 无（完全水平平行） |
| 0.2 | 轻微 (≤6°) | 无 | 无 |
| 0.4 | 明显 (≤12°) | 1~2 层正弦 | 无 |
| 0.6 | 强 (≤18°) | 2~3 层叠加 | 开始出现 |
| 0.8 | 很强 (≤24°) | 3~4 层叠加 | 多条 |
| 1.0 | 极端 (≤30°) | 4~5 层叠加 | 多条强烈断层 |

变形公式：
- **倾斜**：`tan(θ) * (x * cosα + y * sinα)`，θ ∈ [0, 30° * 复杂度]
- **褶皱**：多层正弦波叠加，`Σ A * sin(freq * (x * cosβ + y * sinβ) + φ)`
- **断层**：`throw * tanh(dist / width)`，平滑阶跃避免尖锐不连续

---

## 覆土层生成机制

覆土厚度不是均匀的，而是由 Perlin noise 驱动的不规则分布：

1. 生成 ridged Perlin noise 场（频率比地形噪声更高）
2. 加随机阈值（0.15~0.35）：低于阈值的区域覆土厚度 = 0（**裸露岩层**）
3. 高于阈值的区域：厚度线性映射到 [0, 用户设定最大厚度]
4. 最顶层岩层顶面逐点贴合覆土底面（`max(soil_bottom, prev_top + 0.1)`）

典型分布：约 15~35% 区域完全裸露岩层，其余区域覆土厚度 0~最大厚度不等。

## 导出格式

### 导出网格数据 (.npz)

点击"导出网格数据"按钮，保存为 NumPy `.npz` 压缩格式，包含以下数组：

| 数组名 | 形状 | 类型 | 说明 |
|--------|------|------|------|
| `stratum_id` | (nx, ny, nz) | int32 | 地层标记：0=空气, 1..N=岩层(N=strata数), N+1=覆土 |
| `permeability` | (nx, ny, nz) | float64 | 每个 cell 的渗透系数 K |
| `idomain` | (nx, ny, nz) | int32 | 1=活跃(cell有物质), 0=空白(空气) |
| `top_elevation` | (nx, ny) | float64 | 地表高程（由 Perlin noise 生成） |
| `soil_bottom` | (nx, ny) | float64 | 覆土底面高程（逐点不同，不均匀） |
| `inside_mask` | (nx, ny) | bool | 地块边界掩码（不规则边界） |
| `x, y, z` | 1D | float64 | 三个方向的坐标轴 |
| `dx, dy, dz` | scalar | float64 | 三个方向的网格间距 |
| `n_strata` | scalar | int | 用户岩层数量 |
| `soil_thickness_avg` | scalar | float | 覆土平均（最大）厚度 |

Python 读取示例：

```python
import numpy as np
data = np.load("geology_data.npz")

stratum_id = data["stratum_id"]       # 地层标记
K = data["permeability"]              # 渗透系数
idomain = data["idomain"]             # 活跃/空白掩码
top = data["top_elevation"]           # 地表高程
x, y, z = data["x"], data["y"], data["z"]
dx, dy, dz = data["dx"], data["dy"], data["dz"]
```

### 导出 VTK (.vtu)

点击"导出 VTK"按钮，保存 PyVista ImageData 网格，包含 `stratum_id` 标量场，可在 ParaView 中打开进行高级可视化。

## 核心算法说明

### 生成顺序（从下到上）

```
1. 底层岩层 (strata[0])    → 底面固定在 -depth
2. 中层岩层 (strata[1..])   → 底面 = 上一层顶面
3. 顶层岩层 (strata[-1])    → 顶面逐点贴合覆土底面
4. 覆土层                    → 底面 = 顶层顶面，顶面 = 地形表面
```

### 体素标记体系

```
0      = 空气（地表以上 或 深度以下间隙）
1      = 物理最底层岩层
2..N   = 中间岩层
N+1    = 覆土层（物理最顶层）
```

### Perlin Noise

采用纯 NumPy 实现的 Perlin noise + FBM，无 C 扩展依赖，避免 segfault：
- 256 项 Ken Perlin 原始排列表
- 向量化运算（支持 ndarray 输入）
- 经典 `t^3 * (t * (t * 6 - 15) + 10)` fade 函数

---

## 注意事项

1. **分辨率影响速度**：XY 分辨率 > 150 时，3D 体素数量呈立方增长，生成和渲染会变慢
2. **顶层岩层厚度**：物理最顶层岩层的实际厚度 = 覆土底面 − 前一层顶面，受地形起伏和覆土不均匀性影响，各处不同
3. **覆土厚度 = 0 时**：覆土层不生成，地表直接露出顶层岩层
4. **preset_name 字段**：每个地层独立记录最后一次使用的预设名称，修改渗透系数后不会丢失预设关联
5. **浮点精度**：渗透系数精度为 6 位小数，支持玄武岩 (1e-5) 和花岗岩 (1e-6) 级别的低渗透系数
